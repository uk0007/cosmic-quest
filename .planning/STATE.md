## Key Decisions
1. **Milestone 2 Vision:** Extended existing Cosmic Quest web app into a 2D side-scrolling platformer starring the provided Dog character, using Phaser 3 for gameplay/physics and Three.js for celestial backdrop and portal depth.
2. **Knowledge Gates:** Physical locked gates in the world trigger the existing 60-second Cosmic Quest MCQ modal, pausing gameplay and rewarding/penalizing Energy upon answer.
3. **Non-destructive Integration:** Existing quiz modes (IGKO, ISO, IEO) and Question Studio remain 100% accessible via a dual entry on the Welcome screen.
4. **Asset Preservation:** Used genuine sprites and animations from `2D Stylized Adventure Game Asset Pack` (Dog Idle, Walk, Sniff, Bones, Crystals, Terrain, Doors).
